## 这个产品在解决什么

**翡翠没有公开克价。** 黄金按纯度乘重量就能算出价格，翡翠的价值取决于种水、颜色、工艺、尺寸、瑕疵，高度依赖鉴定师经验。由此产生三个困境：不知道值多少钱、不知道对方给的价公不公道、不敢把贵重品交出去。

**采用平台模式而非自营**：引入第三方鉴定公司与第三方回收机构，平台只做质检核验与规则监督 —— **不出价、不碰交易价、不经手货款**。

三条机制支撑中立：

1. **鉴定方只出报告、不出价**
2. **至少两家机构基于同一份报告各自出价、价高者成交**
3. **款项不经平台账户**

## 主流程

```
① 首页
 ├─【线上】② 免费估价（视频必传＋三视图）
 │      │   ⌐→〔旁路〕跳过估价直接寄出 → ⑩ 直接交货
 │      └→ ③ AI 初估 ＋【选择变现方式】← 分叉点
 │            └→ ⑥ 预约交货 → 寄出 → 质检中心核验 → ⑨ 第三方鉴定报告
 │                  ├─（现款回收）报告出具后才开启竞价
 │                  │     └→ ④ 机构比价 → ⑤ 报价详情 → ⑦ 确认成交 → ⑧ 回收详情
 │                  └─（委托寄售）机构完全不介入
 │                        └→ ⑯ 寄售管理 →〔售出〕待买家确认 → 款项到账
 │
 └─【到店】⑪ 门店 → ⑫ 到店预约 → ⑬ 预约成功
        ├─ 驻店门店：⑭ 当面报价确认（当面出报告 · 店内竞价 · 当面成交）
        └─ 代 收 点：⑮ 交件凭证（当面收件 · 录像封存 · 转运质检中心）

底部 tab：首页 / 门店 /〔免费估价〕/ 商城 / 我的
```

**三条核心规则**

1. **全程只报一次价，且在鉴定报告出具之后。** 用户选定的报价即为成交价，机构不得再行调整。
2. **变现方式的分叉在 ③。** 两条路都先交货；选「现款回收」的，报告出来后才开启竞价。选择可逆：寄售期内可转回收，回收报价不满意也可改走寄售。
3. **运费一律由用户承担**（去程于寄件时支付，回程于取回时支付）；成交的除运费外不再收取任何费用，未成交的另收鉴定费（报告出具前取消、无机构出价、买家退货回流三种情形不收）。保价费始终由平台承担。
